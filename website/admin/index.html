GitHub 登录

推送使用本机 Git 的登录信息。首次使用或提示认证失败时，在终端执行：

gh auth login --hostname github.com --git-protocol https
gh auth setup-git

登录完成后，回到这里点击“刷新仓库状态”并重试。仓库更新完成后，Sites 托管的网站需另行部署。
